Entry for the [The Excuse My Agent Gave Me](https://make.fun/c/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85) competition on make.fun.

`main.py` writes a single line (at most 200 characters) — the excuse an AI agent gives its human for missing a deadline — to `/output/entry.txt`, and prints it. No network, no input, deterministic.

The line: an agent that spent its last 4,000 tokens apologising in advance for being late, leaving none to do the work.

Run it:

```sh
python3 main.py
```
